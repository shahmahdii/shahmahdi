# Shah Mohammad Mahdi Hasan — Research Portfolio

Clean academic portfolio inspired by professional research sites.

## How to put it online (GitHub Pages)

1. Create a GitHub account and a new **public** repository named `portfolio`.
2. Upload these files:
   - `index.html`
   - `profile.png`
   - `cv.pdf`
   - `README.md`
3. Go to **Settings → Pages**
4. Source: **Deploy from a branch** → Branch: **main** → Folder: **/ (root)** → Save
5. Wait 1–2 minutes. Your site will be live at:

   `https://YOUR-USERNAME.github.io/portfolio/`

## Local preview
Just open `index.html` in any browser.
